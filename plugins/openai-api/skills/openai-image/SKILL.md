# OpenAI Image

## 何时调用

本技能为 ZCode、Codex 补充能力。已有材料或本地处理足够时直接完成；需要相应能力时先尝试当前会话实际可用的内置工具。仅在内置不可用、无法满足需求，或用户明确指定本技能或 API 时调用脚本。其他方式按对应工具约定执行。

- **规则图形**：简单几何图形、图标、数据图表、流程图、文字排版和界面优先用 SVG、HTML/CSS、Canvas、Mermaid 等实现。需要 PNG/JPEG 时用可用工具渲染导出；已有 SVG、组件或图表代码优先原地修改。
- **本地处理**：裁剪、缩放、旋转、格式转换、拼接、加字等确定性修改优先使用本地图像工具完成。
- **图像创作**：摄影、复杂插画、材质、绘画质感等适合生成；改变已有图的主体、场景、风格或补画内容时使用编辑能力。
- **交付要求**：用户需要可编辑代码、准确数据或界面实现时，保留对应源码和结构，不以生成图片代替。用户指定本技能、接口或模型时按指定执行；简单图形若明确要求绘画质感，也可使用生成能力。

## 调用

- 文字生成图片用 `generate`，根据本地参考图修改用 `edit`。按用途、主体、构图和文字编写 `prompt`，保留用户原意及指定文案；仅在缺少关键文案、参考图、编辑范围不明或要求冲突时询问。
- 先读[接口参考](references/api.md)。使用 `/usr/bin/python3` 和本技能 `scripts/run.py` 的绝对路径；操作名放命令行，参数以 JSON 写入 `stdin`，随后结束输入。
- 命令总时限至少 720 秒。返回进程标识时继续等待同一进程，勿重复启动。结束后读取退出码和 `stdout` JSON。

## 参数选择

- **模型**：生成默认 `gpt-image-2.6-flare`；复杂构图、密集文字、精细主体关系或用户指定时选 `gpt-image-2.6-sunburst`。编辑默认 Sunburst，用户要求简单快速处理时可选 Flare，不只凭指令长短判断。
- **质量**：`quality`、`complexity` 默认 `high`。草稿可降低质量，简单局部编辑可降低复杂度；需要更高细节时选 `xhigh` 或 `max` 质量。
- **格式**：透明背景、文字、图标、线稿、界面或清晰色块选 PNG；摄影、写实场景和复杂纹理选 JPEG。尊重指定格式；JPEG 与透明需求冲突时先澄清。
- **背景与数量**：默认 `background=opaque`、`n=1`。透明使用 `transparent`，仅限 PNG；需要多个方案时再增加数量。
- **生成尺寸**：按用途选比例，无线索时用 `2560x1440`（16:9）。默认短边约 1440 px，大尺寸约 2160 px；合法尺寸见[尺寸规则与示例](references/api.md#尺寸)。无法推断比例且影响交付时再询问；指定尺寸不合法时提出最接近的方案。
- **编辑**：`image[]` 使用绝对路径，第一张图为主图，其余为参考；明确修改项、保留项和参考图用途。上传原文件，不预先重采样，不使用 `mask`、`markup` 或像素级选区。默认省略 `size`，仅在要求缩放、改变比例或指定尺寸时传入。

## 保存

- 用户指定的目录和文件名优先；否则使用运行主机的 `~/Downloads`，主题使用小写英文短词和连字符。生成使用 `<topic>-generate.<ext>`，编辑使用 `<topic>-edit.<ext>`，例如 `vase-generate.png`、`blue-vase-edit.png`。
- `path` 使用绝对路径，扩展名与格式一致，缺少时补全；JPEG 默认使用 `.jpg`。相对路径按工作区解析，基准不明时再询问；重名和多图序号由脚本处理，无需提前检查。

## 结果

- 完整结果先保存为文件，`stdout` 仅返回元信息。按实际返回路径预览或交付文件，不为预览或交付重复请求。
- 按 `images[].path` 和实际 `size` 交付图片，勿推测重名后的名称；检查 `warnings`，说明请求尺寸与实际尺寸的差异。
- 部分保存失败时，交付错误对象 `saved[]` 中的已有文件，并说明未保存部分。

## 失败

按接口参考的[错误处理](references/api.md#错误处理)处理 `code`。失败不自动重试或换接口重复提交；内置生成仍在进行或结果不明时同样处理。超时、断连或服务错误后，上游仍可能已生成图片。保存失败不重新生成，内容过滤如实告知用户。
