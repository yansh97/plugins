# OpenAI Image

使用 `image-generation`、`image-edit`，参数和返回见[接口参考](references/api.md)。

## 创作

根据用途、主体、构图和文字编写 `prompt`，保留用户原意及指定文案。仅在缺少关键文案或参考图、编辑范围不清、要求冲突时追问。

编辑以第一张图为主图，其余为参考；说明修改项、保留项及参考图用途。上传原文件，不预先重采样，不使用 mask/markup 或像素级选区。

## 参数选择

- **模型**：生成默认 `gpt-image-2.6-flare`；复杂构图、密集文字、精细主体关系或用户指定时选 `gpt-image-2.6-sunburst`。编辑默认 Sunburst，用户要求简单快速处理时可选 Flare，不只凭指令长短判断。
- **质量**：`quality`、`complexity` 默认 `high`。草稿降低质量，简单局部编辑可降低复杂度；极致细节才考虑 `xhigh` 或 `max` 质量。局部编辑强调保留其他内容。
- **格式**：透明背景、文字、图标、线稿、界面或清晰色块选 PNG；摄影、写实场景和复杂纹理选 JPEG。尊重指定格式；JPEG 与透明需求冲突时先澄清。
- **背景与数量**：默认 `opaque`、`n=1`；透明选 `transparent`，仅限 PNG；需要多个方案时再增加数量。

### 生成尺寸

默认短边约 1440 px，大尺寸交付选约 2160 px。下表保持精确比例，并将宽高对齐到 16 的倍数。

| 比例 | 短边约 1440 px | 短边约 2160 px | 用途 |
|---|---|---|---|
| 1:1 | 1440x1440 | 2160x2160 | 头像、图标、方形商品图 |
| 3:2 / 2:3 | 2160x1440 / 1440x2160 | 3264x2176 / 2176x3264 | 横竖幅摄影 |
| 4:3 / 3:4 | 1920x1440 / 1440x1920 | 2880x2160 / 2160x2880 | 插画、产品图、人物、海报 |
| 5:4 / 4:5 | 1840x1472 / 1472x1840 | 2720x2176 / 2176x2720 | 商品展示、社交配图 |
| 16:9 / 9:16 | 2560x1440 / 1440x2560 | 3840x2160 / 2160x3840 | 演示配图、视频封面、壁纸 |

按用途选比例，无线索时用 `1920x1440`；比例影响交付且无法推断时再询问。自定义尺寸核对[尺寸限制](references/api.md#参数与默认值)，不合法时提出最接近的方案。

### 编辑尺寸

默认省略 `size`，由服务根据主图计算合法尺寸。仅在用户要求超分、降分、改变比例或指定尺寸时传入；其余参考图不决定尺寸。

## 保存

1. **目录**：用户指定项优先，否则使用系统下载目录；相对目录按工作区解析，基准不明时再询问。
2. **文件名**：用户指定项优先，否则按内容命名；扩展名与格式一致，缺少时补全。
3. **调用**：将目录与文件名合成为 `path` 绝对路径，`image` 也用绝对路径。重名序号由 MCP 处理，无需提前检查。

下载目录以 MCP 服务所在系统为准：

| 系统 | 定位方式 |
|---|---|
| macOS | `~/Downloads` |
| Windows | 查询 Downloads Known Folder，尊重系统重定向 |
| Linux | 读取 `~/.config/user-dirs.dirs` 的 `XDG_DOWNLOAD_DIR`，未配置时用 `~/Downloads` |

## 交付与失败处理

按 `images[].path` 和实际尺寸交付，检查 `warnings`；部分保存失败时交付 `saved` 中的已有文件。

参数或路径问题修正后再调用；配置、密钥、权限和余额问题提示用户处理，不读取或输出密钥。超时、断连或服务错误可能已产生图片，不自动重试。
