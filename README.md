# yansh97/plugins

为 ZCode、Codex 等编程助手补充网页检索、文档识别、语音处理和图片生成能力。支持 ZCode、Codex 插件市场安装，插件按厂商组织，同一插件内的技能共用一份 API 密钥。

## 插件

| 插件 | 版本 | 功能 |
|---|---|---|
| [DeepSeek API](#deepseek-api) | 0.1.0 | 网页搜索与抓取、文档识别、语音转写与合成 |
| [OpenAI API](#openai-api) | 0.1.0 | 图片生成与编辑 |

## 能力选择

插件用于补充客户端能力。已有材料、结果或本地处理足够时直接使用；确需检索、识别或生成时，优先尝试当前会话可用的内置能力。内置不可用、无法满足需求，或明确指定插件或 API 时，再调用外部接口。

| 任务 | 选择依据 |
|---|---|
| 网页信息 | 已提供的正文、本地文件足够时直接处理；需要外部信息或核验来源时先用内置检索、网页阅读，能力不足时再用网页技能 |
| 文档与图片识别 | 能直接读取的文字优先从原文件提取；扫描件、提取不完整或需要逐页版面、坐标时再考虑 OCR。只需理解画面时优先直接看图 |
| 语音转写 | 已有转写稿足够时直接整理；需要从录音获取文字时先用内置音频理解或转写，能力不足时再用 ASR |
| 语音合成 | 仅修改朗读稿时直接处理文本；需要朗读或交付音频时先用内置能力，声音、格式或文件交付无法满足要求时再用 TTS |
| 图片创作 | 简单几何图形、数据图表、流程图、文字排版和界面优先用 SVG、HTML/CSS、Canvas 等绘制，按需渲染导出；摄影、复杂插画、材质或其他需要图像生成的内容再使用生成能力 |
| 图片修改 | 裁剪、缩放、旋转、格式转换、加字等优先本地处理；需要改变主体、场景、风格或补画内容时再使用图像编辑能力 |

内置调用仍在进行，或 OCR、音频、图片请求超时后结果不明时，不自动换用另一接口重复提交。用户指定的工具、模型和交付格式优先。

## 运行要求

- macOS，且提供 `/usr/bin/python3`（Python 3.9 或以上）。无需额外安装 Python 依赖。
- 运行技能的客户端能够执行本地脚本。使用远程工作区时，运行脚本的主机也必须是 macOS。
- 所用 API 的有效密钥及可用额度。

## 安装

### ZCode

在 ZCode 的「设置 → 插件 → 创建 → 添加插件市场」中填入仓库地址 `https://github.com/yansh97/plugins`，然后安装并启用所需插件。也可以使用本地仓库的绝对路径添加市场。

客户端操作说明见 [ZCode 插件文档](https://zcode.z.ai/cn/docs/plugin)。

### Codex

使用 Codex CLI 添加市场：

```bash
codex plugin marketplace add yansh97/plugins
```

本地使用时，将仓库地址替换为本地仓库的绝对路径。添加后，在客户端的插件目录中选择 `yansh97` 市场，安装并启用所需插件。

两种客户端共用下方配置，无需分别填写密钥。市场与插件格式见 [OpenAI 插件文档](https://developers.openai.com/plugins/build/plugins)。

## 配置

创建 `~/.config/agents/config.json`，按需填写以下配置。目录不存在时先创建目录；也可以复制仓库中的[示例配置](config.example.json)。

```json
{
  "deepseek-api": {
    "api_key": ""
  },
  "openai-api": {
    "api_key": "",
    "base_url": "https://api.openai.com/v1"
  }
}
```

将 `api_key` 替换为对应厂商的 API 密钥，只需保留使用的插件配置。DeepSeek 密钥可在 [DeepSeek 平台](https://platform.deepseek.com)创建，供网页、OCR 和音频技能共用。

OpenAI 的 `base_url` 为必填项，需包含版本前缀，如 `https://api.openai.com/v1`，无需追加具体接口路径。接入地址需支持下文列出的图片模型和文件上传。

配置文件使用 UTF-8 JSON，不支持注释或尾随逗号。已有配置请手动合并所需字段；修改后下次调用生效。请勿将实际密钥提交到仓库。

## 使用

安装并配置后，直接描述需求，也可以输入 `$` 或 `/` 选择技能。技能按任务加载，所有操作均等待完整结果后返回，不提供实时流式交互。

## 结果与文件

网页操作直接返回 JSON；其余操作先保存完整结果，再返回实际路径、大小及操作相关元信息。按任务读取文本、预览媒体或交付文件，不默认将完整文件内容带入模型上下文；格式转换和内容整理基于已保存文件处理，无需再次请求接口。

用户指定的目录和文件名优先；未指定时使用运行主机的 `~/Downloads`，按 `<topic>-<operation>.<ext>` 命名。主题使用简短的小写英文词，词间用连字符；扩展名按实际格式选择，JPEG 默认用 `.jpg`。

| 操作 | 文件内容 | 文件名示例 |
|---|---|---|
| `ocr` | 完整识别 JSON，保留页码和版面信息 | `report-ocr.json` |
| `asr` | 完整转写 JSON，保留文字和时长等信息 | `message-asr.json` |
| `tts` | WAV 或 PCM 音频 | `welcome-tts.wav` |
| `generate` | PNG 或 JPEG 图片 | `vase-generate.png` |
| `edit` | PNG 或 JPEG 图片 | `blue-vase-edit.png` |

自动创建目录。重名时在扩展名前追加 `-1`、`-2`；一次生成多张图片时从 `-1` 开始编号，已有序号顺延，不覆盖文件。以返回的实际路径为准。

| 技能 | 操作 | 接口参考 |
|---|---|---|
| `deepseek-web` | `search`、`fetch` | [网页搜索与正文抓取](plugins/deepseek-api/skills/deepseek-web/references/api.md) |

| `deepseek-audio` | `asr`、`tts` | [语音转写与合成](plugins/deepseek-api/skills/deepseek-audio/references/api.md) |

### 使用示例

- 查找 Python 3.9 的官方发布说明，附上来源。
- 阅读这个网页，提取安装步骤。
- 提取 `scans/report.pdf` 中的文字，按页整理。
- 把 `recordings/message.wav` 转写成文字。
- 用女声朗读这段文字，保存到 Downloads。

### 默认行为与限制

请求直接发送到 DeepSeek 官方接口。

- **网页检索**：搜索默认返回 10 条结果，请求总时限为 45 秒。网页地址不能包含用户名或密码；需要登录或依赖脚本渲染的页面可能无法读取。
- **文档识别**：支持本地 PDF、Word、PowerPoint 和图片，按文件内容识别格式，无需预先转换。默认提取文字；需要版面、区域定位或将 Office 文件逐页识别时，使用版面识别模式。文件大小不超过 100 MiB，页数不超过 1000 页，请求总时限为 210 秒。结果可能包含版面标记，达到输出上限的页面会标为不完整。
- **语音转写**：支持 16-bit PCM WAV 和 Ogg Opus，文件大小不超过 8 MiB，时长不超过 120 秒。语言自动识别，双声道仅识别左声道；完整上传后保存转写结果，请求总时限为 660 秒。
- **语音合成**：默认使用女声 `stella`，可选男声 `tide`，默认过滤 Markdown。每次最多 10000 个计费字符（汉字计 2 个，其他字符计 1 个），JSON 请求体最多 64 KiB，请求总时限为 1800 秒。

合成音频默认保存为 WAV，也支持裸 PCM。音频完整接收后再保存，传输中断时不会保存未接收完整的音频。

## OpenAI API

| 技能 | 操作 | 接口参考 |
|---|---|---|
| `openai-image` | `generate`、`edit` | [图片生成与编辑](plugins/openai-api/skills/openai-image/references/api.md) |

### 使用示例

- 生成一张 16:9 的陶瓷花瓶产品图，浅灰背景。
- 把 `images/vase.jpg` 中的花瓶改成蓝色，保留光照和背景。

### 默认行为与限制

生成默认使用 `gpt-image-2.6-flare`，尺寸为 `2560x1440`（16:9）；编辑默认使用 `gpt-image-2.6-sunburst`，尽量保持主图尺寸。默认使用高质量，按场景选择 PNG 或 JPEG。编辑需要本地参考图和文字说明。

请求直接发送到配置的接入地址，总时限为 600 秒。输入和生成结果均可能被内容过滤。模型、尺寸和文件限制见接口参考。

## 失败与重试

参数或文件不符合要求时，先修正后再调用；配置、密钥、余额或权限问题需要处理后才能继续。

网页检索遇到限流、网络或服务临时故障时，技能最多重试一次。文档识别、音频处理和图片生成失败后不自动重试；超时或断连后，上游仍可能完成处理并计费。
